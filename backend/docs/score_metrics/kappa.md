# Cohen's Kappa

這一份文件說明可用的 score metric 及其設定。

## 類別: score_metrics

## 說明

Cohen's Kappa 係數，在扣除隨機一致性之後衡量分類器與真實標籤的一致程度。

公式：`κ = (Po - Pe) / (1 - Pe)`，其中 Po 為觀察一致率，Pe 為隨機一致率。

解讀參考：
- κ > 0.8：高度一致
- 0.6 < κ ≤ 0.8：中度一致
- 0.4 < κ ≤ 0.6：尚可接受
- κ ≤ 0.4：一致性差

## 適用場景

- 醫學評分者一致性研究
- 多分類問題的效能評估
- 論文需要報告比 accuracy 更嚴謹的指標時

## 可用參數

- `metric`: `"kappa"`

## 範例

```json
{ "id": "s0", "metric": "kappa" }
```
